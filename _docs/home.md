# Welcome to the Wiki!

This wiki provides documentation for **Engine**, an open-source, block-based 3D coding environment built with Babylon.js and Blockly.

## Documentation Pages

* **[Installation](./installation.md):** How to run and serve the project locally.
* **[Usage](./usage.md):** An overview of the 3D editor interface, creating 3D objects, handling actions, and scripting events.
* **[Assets & Free Resources](./assets.md):** Free-to-use/open-source 3D models, textures, audio resources, creation tools (including [audio.digitaleducationsafety.org](https://audio.digitaleducationsafety.org/)), and licensing/attribution guidance.
* **[Digital Co-Host Avatar Guide](./cohost.md):** Guide and code/block examples for procedural flight physics, speech recognition, webcam spatial tracking, retro voice synthesis, and OBS Studio integration.
* **[Input Controls Evaluation](./input_controls_evaluation.md):** Overview of cross-device input mapping (mobile gestures, desktop mouse/keyboard, touchpad, and gamepads) and unified action systems.
